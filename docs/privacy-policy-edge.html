Bookmark Tidy Privacy Policy

Effective date: August 9, 2026

Bookmark Tidy is a Microsoft Edge extension that helps users scan, review, organize, and undo changes to their Microsoft Edge favorites. This policy explains what information the extension accesses, how it is used, and how it is stored.

Information Bookmark Tidy accesses

When you choose to scan your favorites, Bookmark Tidy accesses the favorites tree provided by the Microsoft Edge Bookmarks API. This can include:

  • favorite titles and URLs;
  • folder names and folder structure;
  • favorite and folder identifiers;
  • favorite position and ordering;
  • favorite creation timestamps, when Microsoft Edge provides them; and
  • derived information such as normalized URLs, domains, duplicate groups, and organization suggestions.

Bookmark Tidy does not request access to webpage contents, browsing history, passwords, cookies, authentication information, payment information, or personal communications.

How the information is used

Favorite information is used only to provide Bookmark Tidy's user-facing features:

  • scan the favorites library;
  • identify duplicate favorites and empty folders;
  • suggest favorite organization changes;
  • display proposed changes for review;
  • apply only the changes the user explicitly selects and confirms; and
  • undo successful operations from the latest batch.

Bookmark Tidy does not use favorite information for advertising, profiling, credit decisions, or any unrelated purpose.

Local processing and storage

Favorites analysis is performed locally in the extension on the user's device.

To provide the undo feature, Bookmark Tidy stores the latest operation batch in chrome.storage.local. Microsoft Edge uses this Chromium-compatible API to store data locally within the extension. That record can contain favorite metadata associated with the reviewed operation, including titles, URLs, identifiers, folder locations, ordering, operation status, and error details. The latest record remains in local extension storage until it is replaced by a later batch, the extension's local data is cleared through Microsoft Edge, or the extension is uninstalled.

Data transmission and sharing

Bookmark Tidy does not transmit favorite information or operation records to the developer or to external servers. It does not include analytics, telemetry, advertising services, or other third-party data services.

Bookmark Tidy does not sell, rent, share, or otherwise transfer user data to third parties.

Permissions

Bookmark Tidy requests only these Microsoft Edge extension permissions:

  • bookmarks: used to read the favorites tree, show cleanup and organization suggestions, apply user-confirmed changes, and restore affected favorites during undo.
  • storage: used to save the latest operation batch locally so the user can review results and undo that batch.

User choices and control

Scanning begins only when the user selects the scan action. Scanning itself does not modify favorites. Favorite changes require the user to select suggestions and confirm the batch before it is applied.

Users can remove Bookmark Tidy's locally stored operation record by clearing the extension's data through Microsoft Edge or uninstalling the extension. Uninstalling Bookmark Tidy does not reverse favorite changes that were already applied.

Security

Bookmark Tidy keeps handled favorite information within the extension and Microsoft Edge's local extension storage. Because the extension does not transmit this information, it does not send favorite data over a network. Users should still protect access to their device and Microsoft Edge profile.

Single-purpose disclosure

Bookmark Tidy uses information obtained from Microsoft Edge extension APIs only to provide its single purpose: helping users safely scan, review, organize, and undo changes to their favorites.

Children's privacy

Bookmark Tidy is a general productivity tool and is not directed to children under 13. The extension does not knowingly collect personal information from children.

Changes to this policy

This policy may be updated when Bookmark Tidy's functionality or data practices change. The effective date at the top of this page will be revised when an update is published. Material changes will be disclosed as required by applicable Microsoft Edge Add-ons policies.
